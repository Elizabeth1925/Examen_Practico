# Atomic Design

- Átomos: label, input, select, botón, enlace, icono de estado.
- Moléculas: campo con ayuda/error, grupo de acciones, tarjeta de resumen.
- Organismos: formulario de reserva, stepper, panel de confirmación.
- Plantillas: flujo centrado de tres pasos.
- Páginas: inicio, datos, revisión y resultado.

Todos los controles tienen nombre accesible, foco visible y contraste suficiente.
