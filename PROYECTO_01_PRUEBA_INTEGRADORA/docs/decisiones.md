# Decisiones y comparación v1 → v2

Se eligió código HTML/CSS/JS porque permite comprobar teclado, validación, estados y adaptación móvil con profundidad funcional media y fidelidad visual media.

| Aspecto | v1 | v2 | Motivo de diseño |
|---|---|---|---|
| Jerarquía | formulario directo | bienvenida y pasos | anticipar el recorrido |
| Prevención | validación básica | revisión antes de confirmar | reducir envíos accidentales |
| Recuperación | mensaje general | mensaje accionable y borrador | proteger el esfuerzo |
| Accesibilidad | semántica base | skip link, foco, aria-live | mejorar percepción y operación |

Estas son decisiones de diseño planificadas, no mejoras atribuidas a pruebas reales.
