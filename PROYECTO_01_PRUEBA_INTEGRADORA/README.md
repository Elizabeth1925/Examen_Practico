# Proyecto 01 - Prueba integradora IHC

Proyecto de práctica, no evidencia auténtica de una evaluación presencial. El escenario simulado es una reserva de tutoría universitaria.

## Ejecutar

Abre `prototipo/v1/index.html` o `prototipo/v2/index.html` en un navegador moderno. No requiere servidor, base de datos ni dependencias.

## Recorrido sugerido

1. Inicia una reserva y prueba enviar campos vacíos.
2. Completa los datos y revisa el resumen.
3. La primera confirmación genera deliberadamente un error recuperable; los datos permanecen.
4. Reintenta para ver carga y éxito.
5. Recorre con Tab, Shift+Tab, Enter y Escape.

## Versiones

- v1: estructura funcional inicial y feedback básico.
- v2: jerarquía visual, resumen previo, foco visible, regiones vivas y recuperación más explícita.

Los resultados de pruebas, cuentas, Issues, commits y PR reales deben completarse únicamente después de ejecutarlos.
