# Proyecto 02 - Doce casos IHC

Colección de ejercicios independientes basados en las tarjetas. Cada carpeta incluye su propio HTML, CSS y JavaScript y no depende de otro caso.

Abre `casos/IHC-XX/prototipo/index.html`. La primera confirmación simula un error recuperable y la segunda completa el flujo. No se usan datos reales.

Las incidencias sorpresa se transcriben únicamente en `documentacion/incidencias-sorpresa.md`; no están implementadas ni anunciadas dentro de los prototipos.
